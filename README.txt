VELORA - متجر إكسسوارات مجاني
================================

الملفات:
- index.html
- style.css
- script.js

قبل النشر:
1) افتح script.js.
2) غيّر قيمة WHATSAPP إلى رقم واتساب الذي يستقبل الطلبات.
3) استبدل أسماء المنتجات والأسعار والرموز في مصفوفة products بمنتجات المورد الحقيقية.
4) يمكن استبدال الرموز لاحقًا بصور المنتجات الحقيقية.

الموقع Static ولا يحتاج قاعدة بيانات أو استضافة مدفوعة.
يمكن نشره مجانًا عبر GitHub Pages أو Netlify.
